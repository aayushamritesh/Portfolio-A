# Ashwini S. Gudekar – Personal Research & Portfolio Website

A modern, light-themed portfolio website designed for **Ashwini S. Gudekar**, M.Tech Computational Biology candidate at **IIIT Delhi**, specializing in **Single-Cell Genomics**, **Clinical NLP**, and **Machine Learning**.

---

## 🎨 Design Philosophy & Theme

- **Aesthetic**: Luminous Light Theme featuring crisp, fresh gradients of light blue (`#0ea5e9`, `#0284c7`, `#38bdf8`) across an ice-white and soft sky backdrop (`#f8fbff` and `#f0f7fe`).
- **Interactive Cursor Spotlight**: Information cards dynamically track mouse coordinates (`--mouse-x`, `--mouse-y`) to cast a soft, luminous light-blue spotlight ray across their surfaces.
- **Natural Interaction Hierarchy**: Information cards maintain a calm, stable presentation with spotlight illumination, while functional buttons, navigation links, and project CTAs feature clear highlight-on-hover effects.
- **Static Portrait Frame**: Ashwini's portrait is presented in an elegant, static glass frame with a soft ambient aura, with no button-like hover distractions.
- **Balanced Card Architecture**: Symmetrical project cards with unified header spacing, streamlined badges, and matching typography.

## 🚀 Local Development & Preview

To run and preview the website locally:

```bash
# Navigate to the portfolio folder
cd "Portfolio-A"

# Start a simple HTTP server using Python:
python -m http.server 8000
```

Open `http://localhost:8000` in any web browser.

---

## 🌐 Deployment

The website consists of static HTML5, CSS3, and modern Vanilla JavaScript with zero server dependencies. It can be instantly deployed to:
- **GitHub Pages**: Push this directory to a repository and enable GitHub Pages in Settings -> Pages.
- **Vercel / Netlify**: Drag-and-drop the `Portfolio-A` folder directly into the dashboard.
